# 动感条（kinetic-reel 方法论）

目标质感：编辑感强烈的大字报动效条 / showreel：压缩粗黑标题、HUD 微字、
黑/奶油/柠檬绿配色、连续形变转场、节拍锁定的合成配乐。

## 核心原则

1. **字是主角**：超压缩展示体做标题，宽 grotesk 做重锤，等宽体做一切标签。
   中英双语观众时：大英文标题 + 小中文注解。
2. **每个镜头有机构**：不只是字——网格布线、矩阵扫描、令牌跳状态机、
   列表熔合、数据包过闸。标题说出它，机构证明它。
3. **节拍锁定**：字母、徽章、计数器、切点全部坐在节拍上。快进（expo-out）、
   停留、下一个。章内尽量用连续形变转场（穿过眼睛正盯着的元素、
   从刚点亮的东西里放大光圈），章间才用硬切 + 重锤。
4. **事实神圣**：只用给定的数字，标注适用范围；示意性内容标 SCHEMATIC。
   没有的数据不画。
5. **无噪声嗖嗖声**：章前音垫推进，章内安静点题，约一半切点留白。

## Tempus 实现

- cues：`const S = {...场景起点帧}; const hits = [节拍帧...];`
- 每镜一个函数 `shotN(t)`，整体走 Sequence 串接；
- HUD：顶部角落细字 + 分段进度条（章节结构可视）；
- 中文字符注意字体子集（无网络，用系统字体：Microsoft YaHei / Segoe UI）。
