# 逐帧手绘动画（painted-animation 方法论）

目标质感：水彩 + 墨线的手绘逐帧动画（MV、歌词视频、卡通短片）。
在 Tempus 里用 Canvas 2D + 确定性笔刷抖动实现"像逐帧不像代码"。

## 核心原则

1. **手作质感**：只有手绘笔触（画笔填充 + 墨线描边），不用生硬的几何 fill/rect。
   平面 2D；转面靠画出的关键视角，不做 3D 投影。
2. **无文字**：不出字幕/标签/对白气泡（歌词视频的逐字卡拉OK除外），
   信息用画面表达，反应用画出的表情符号（汗滴、感叹、爱心）。
3. **每镜有事**：事件、因果、伏笔回收，至少占一样。没有事件的镜头删掉。
4. **给观众时间**：每镜列出 reads（观众必须读到的信息点），一次一个 read；
   快动作 + 停留含义；镜头长度由 reads 决定。
5. **活着**：没有东西是死的。idle 微动、漂移镜头、墨线沸腾（boil）；
   表情渐变而不是切换；角色占画面够大。
6. **缝缝有转场**：笔刷擦除、光圈、甩镜、匹配剪辑、动作接动作。
7. **一件作品**：一个世界、一条色彩弧线、一条情绪线、首尾呼应。

## Tempus 实现

- 画布：`<canvas width={width} height={height}>`，在 useFrame 里全量重绘。
- 沸腾线（boil）：轮廓每帧微抖，用确定性哈希代替随机：
  `const j = (i) => Math.abs(Math.sin(i * 12.9898 + frame) * 43758.5453) % 1 - 0.5;`
  （注意：frame 参与哈希是允许的，因为每帧仍是纯函数）
- 水彩填充：多层半透明叠加 + 边缘渗透（多层描边不同透明度）。
- 背景禁止平涂：草地 = 底色 + 笔触纹理 + 前景草簇分层；水面 = 色带 + 波纹笔触。
- 角色设定集（model sheet）：先画定角色三视图与表情表，再进镜头，全程保持 on-model。

## 工作流

1. 先写分镜（logline、世界与色彩弧线、motif、情绪弧线、逐镜 reads）。
2. 先摆关键姿势（关键帧），逐帧检查造型，再补中间动态。
3. 逐镜渲染检视循环：关键帧拼图 → 动作条带 → 细节裁切，每次都对照检视清单修正。
4. 卡拉OK：歌词逐字上色，节拍点用 mark() 登记。

## 检视清单（每镜必查）

- 事件清楚？角色够大？reads 时机对吗？
- 预备动作 / 跟随 / 无瞬移？脚和道具接触地面了吗？
- 每个接缝有转场？没有文字 / 3D / 纯黑白？光晕没有糊成一团？
- 每帧成本控制在可渲染范围（形状数量）？
