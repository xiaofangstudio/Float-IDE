# Motion Studio 总控（Tempus 版）

全融合「动画 / 宣传片」生成链。凡"做动画 / 做宣传片"，先判定大类，再路由方法，
再叠加九大增强。所有产出一律用 Tempus 运行时（`import { ... } from 'tempus'`）实现。

## 〇、前置监测：动画还是宣传片？

| 判定 | 走哪条方法 |
|---|---|
| 逐帧手绘 / 水彩 / 墨线 / 卡通 / MV / 歌词视频 / "像逐帧不像代码" | painted-animation |
| 动感条 / showreel / 大字报 / 节奏图形动效 | kinetic-reel |
| 产品宣传 / 品牌片 / 广告 / 发布 / teaser / 功能演示 | onetake |
| 一句话复杂成片（角色+音效+后期+多风格） | remotion-plus 思路 + director-grade 纪律 |
| 真 2D 手绘短片 / 像素 / 几何叙事 | director-grade |
| 转码 / 拼接 / 抽帧等媒体处理 | 交给外部 ffmpeg（Tempus 内置仅编码导出） |

混着说（"宣传片式的动画"）：有水彩/逐帧词 → 动画；有品牌/产品/发布词 → onetake。

## 一、意图理解（先听懂，再动手）

拆解每句话：MV 还是宣传片还是演示片？情绪基调、镜头风格、时长。
缺时长/风格/节拍/角色时自动补齐并显式告知（最多一次澄清）。
产出规格：题材、基调、时长（秒→帧）、BPM/节拍点、镜头清单。

## 二、九大增强（对所有路由统一生效）

1. **意图理解与逐字补全**：缺什么补什么，标注推断项。
2. **稳定性保障**：每帧是 t 的纯函数；图层先背景后前景；时间轴由节拍表驱动。见 tempus-api.md。
3. **超长分段**：长片拆多个 Sequence 段落组织代码；导出由渲染器逐帧处理。
4. **画面无空位校验**：渲染后人工抽帧检查，无大块空白、无空帧。
5. **规格自动补全**：时长、节拍、镜头数按类型预设补齐。
6. **物理感**：spring() 是默认运动语言；落地用 outBack/outElastic；不用手写物理循环。
7. **可编码质感**：把"手绘/颗粒/微动"编码为确定性参数（噪声哈希、抖动幅度、笔刷纹理）。
8. **宣传片风格库**：微软 Fluent（轻浮动+柔和弹簧）、苹果极简（大字+呼吸节奏）、打字机（逐字定格+滴答）、摄像机（推拉摇移跟）、转场（缩放穿越/光圈/匹配剪辑）。
9. **确定性渲染**：同帧同画面；禁止随机与实时时钟。

## 三、统一工作流（七步）

1. **判大类**：动画 or 宣传片。
2. **意图理解**：补全规格。
3. **路由**：选方法论（见下四篇技能）。
4. **写分镜**：镜头清单（每镜：内容、起止帧、读点 reads、节拍、转场）。
5. **写代码**：每镜一个文件 `src/scenes/shotN.tsx`，入口按 Sequence 串接；遵守确定性纪律。
6. **预览校对**：逐镜空格播放 + 左右逐帧，检查 reads 是否清晰、转场是否衔接。
7. **导出交付**：Ctrl+E 或 MCP render_video，检查成片无空帧。

## 四、验收清单（强制）

- 大类判定正确、路由正确？
- 每帧都是 t 的纯函数？
- 每个镜头都有事件（发生了什么），而不是静态展示？
- 每个切点都有衔接物（什么元素带过去了）？
- 节奏有长短变化（0.25s 的字挨着 2.5s 的停留），不是节拍器？
- 标记（mark）已打点，时间轴可读？
- 导出后逐帧抽查无空帧、无错帧？
