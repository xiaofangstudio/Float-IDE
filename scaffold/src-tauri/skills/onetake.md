# 宣传片一镜（onetake）

产品宣传片 / 功能演示 / launch 片的方法论。核心信条只有一句：
**节拍互相衔接（carry），而不是互相替换（replace）。**
节奏对了但每个节拍替换上一个，观感仍是 PPT；每个节拍从上一个里长出来，才是影片。

在 Tempus 中落地：每部片是一个合成（registerComposition），每帧是 frame 的纯函数 ——
这天然满足 onetake 的确定性要求（同一时间同一画面），所以本技能的所有纪律都可以直接执行。

## 适用 / 不适用

- 适用：产品发布片、teaser、功能演示（15–60s）、品牌介绍、以真产品为本的动效短片。
- 不适用：长视频、真人素材剪辑、逐帧手绘动画（走 painted-animation）、大字报动感条（走 kinetic-reel）。

## 八步流程

### 1. 解构参考片（有参考片才做）

用 ffmpeg 抽帧看数字，不要凭一眼印象：
静帧占比（高端片约 1/3 时间几乎不动）、切点分布（硬切是否聚集成爆发组）、
元素大小与留白、快动作是否有运动模糊（t80 是 snap 还是 S 曲线）。
没量过就动手，最容易犯「均匀节奏」——每个镜头差不多长，直接被判定为 PPT。

```bash
ffprobe -v error -show_entries format=duration 参考片.mp4
ffmpeg -ss 0 -i 参考片.mp4 -vf "fps=2,scale=480:-1,tile=6x5" sheet.jpg
```

### 2. 概念先行：三个中心想法，再写分镜

概念是「关于画面的一句话」，不是关于产品的一句话。写三个在**中心想法**上不同的：

- **一个元素贯穿变形**：圆点是光标 → 裂成分区 → 空成加载环 → 展开成曲线 → 落在 logo 的 i 上；
- **一次运镜穿尺度**：从光标内部拉开到输入框，穿过发送键进入作品，再从成片里钻出来；
- **因果链**：每个节拍是引发下一个节拍的碰撞（光照亮桌面机器 → 碰撞推倒下一站）；
- 或 转折分屏 / 物理隐喻 / 一块连续表面……

每个概念写清：钩子帧、每个边界靠什么衔接、它禁止什么（没有卡片？没有硬切？）、用什么色调。
三个一起给用户挑。**禁止默认沿用上一次的模板故事**——新片子套旧节拍，无论多精致都读作模板。

### 3. 分镜 = 节奏 + 衔接

逐节拍写：`t · 节拍 · 什么在动 · 什么静止 · 靠什么衔接到下一拍`。

节奏规则：
- 镜头时长至少 4 倍差异（0.25s 的字撞在 2.5s 的静持旁边）；
- 至少一段画面与声音近乎全静；
- 讲一个故事（概念的），不是清单；
- 小元素、大场地（约七成画面是留白），满屏画面是例外；
- 禁止切在节拍器上——等长镜头 = 幻灯片。

衔接规则：
- 每个段落边界，说出**那个活过边界的东西**：手、主体、变成下一场景的容器、
  从主体里开出的舞台、推进卡片直到它变成场景的运镜；
- 说不出活口 = 换页，无论节奏多好；
- 例外只有两处：爆发组的硬切连击、片尾卡。

### 4. 素材：真 UI 重建，不截屏贴图

演示产品界面时，把 UI 用 JSX 重建（Tempus 的优势：UI 就是组件）：
- 每个字符串进表格，每个状态是 `set(state)` 的纯函数；
- 重建件放在「运镜平面」上，运镜可随时推进任意倍率（transform: scale 由 frame 推导）；
- 要展示用户操作，就画出手：光标路径也由 frame 的纯函数生成，观众必须看到「因」；
- 永远不要把一整页缩成小缩略图指望观众看清——要么满屏带手，要么把组件摘进卡片里实时演。

### 5. 作画：从库选动作，曲线按角色定

- 进场用快出（outExpo，snap 感），落地用 outBack / outElastic，匀速只给机械；
- **运镜要「跟拍」而不是「钉死」**：镜头追逐每个节拍框住的对象——滞后、侧倾、落定。
  纯静止镜头是最常被指出的问题（「就缺灵动的跟踪运镜」）；
- 用 mark() 把节拍登记到时间轴，方便对齐与验收；
- 快动作必须有运动模糊（blur 由速度推导），否则频闪成重影。

### 6. 声音：一套材质，一个房间

- 一种材质组（气/木/玻璃/低频/气泡）+ 一个混响空间，全片统一；每个事件独占一个音色 = 听觉版幻灯片；
- 事件比节拍少：不是每拍都有声；约一半切点处留静默；
- 音乐选可商用免版税曲源并记录来源；人声在时压音乐（ducking）；
- 峰值 -8 dBFS 留给音乐叠加，成片响度约 -16 LUFS。

### 7. 渲染与验收

```bash
# 在 Tempus 内导出 MP4（1920x1080，CRF 16-20）后用 ffmpeg 抽查
ffmpeg -ss 6.0 -i film.mp4 -frames:v 1 check_6s.png
```

验收清单（任一不过即返工）：
- [ ] 节奏：镜头长度有 4 倍以上差异？有整段静持？
- [ ] 衔接：每个边界都说得出活过边界的东西？
- [ ] 曲线：快动作有模糊、无频闪重影？
- [ ] 取景：标记过「绝不能出框」的对象是否全程在框内？
- [ ] 一帧一问：随便抽一帧，能说出「这帧在讲什么」吗？
- [ ] 确定性：同帧重看完全一致（Tempus 天然满足，但禁止 Math.random/Date.now 违例）。

### 8. 交付

1080p30 草稿先给用户过目，**通过后才出更高规格**。MP4 复制到工程根目录交付。

## 硬规则（每条都是踩过的坑）

- 永远不默认上一部片的模板故事；三个概念让用户挑。
- 永远不把上一部片的外观带进下一部；色调、舞台、运镜语法、转场每次重新选。
- 永远不在节拍器上切；等长即幻灯。
- 永远不替换节拍——要衔接；display:none 式互斥换场就是换页。
- 永远不让画面永远在动；静默让爆发成立。
- 永远让「因」可见；没有原因的画面变化读作屏保。
- 永远用小元素、大场地。
- 一切确定性：Tempus 纪律与本技能同源，同 t 同帧。
